# Frontend Roadmap

## Current State

The app has route-level pages for home, dashboard, template discovery, portfolio creation, and portfolio detail. It includes API service wrappers, IPFS upload helpers, Stellar utility helpers, Zustand stores, domain helpers, reusable UI primitives, and local fallback fixtures.

## Next Milestones

1. Replace demo Stellar identity creation with production wallet or passkey onboarding.
2. Add a test runner and baseline coverage for domain helpers, hooks, and route workflows.
3. Code-split route bundles and isolate Stellar SDK usage behind wallet flows.
4. Build credential linking and proof-of-work submission UI.
5. Add template detail and purchase flows.
6. Add dashboard filtering, search, pagination, and bulk operations.
7. Define public portfolio rendering and metadata sanitization rules.
